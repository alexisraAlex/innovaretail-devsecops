# Política básica de seguridad – InnovaRetail

1. No publicar contraseñas, tokens o claves privadas.
2. Utilizar variables protegidas de GitLab para datos sensibles.
3. Utilizar Kubernetes Secrets para configuraciones sensibles.
4. Ejecutar Trivy sobre el sistema de archivos y la imagen.
5. Clasificar los hallazgos por severidad.
6. Corregir o justificar los hallazgos HIGH y CRITICAL.
7. Ejecutar el contenedor con usuario no privilegiado.
8. Mantener imágenes y dependencias actualizadas.
9. Documentar riesgos aceptados y acciones de mitigación.
